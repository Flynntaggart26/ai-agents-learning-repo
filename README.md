# AI Agents: Pratik Öğrenme Deposu

Kapsamlı, İngilizce, açık kaynaklı bir yapay zeka ajentleri kılavuzu — ajetlerin ne olduklarını, nasıl çalıştıklarını, nasıl inşa edildiklerini, nasıl kullanıldıklarını ve daha derin araştırma için ücretsiz kaynakları kapsıyor. "Ajent nedir?" dan "Kendi çalışan ajentimi inşa edebiliyorum" na doğru gitmek isteyen öğrenenler için tasarlandı.

> **Hedef:** Ajent deneyimi olmayan herkesin bu depoyu okuyabilmesi, örnekleri çalıştırabilmesi ve kendi çalışan yapay zeka ajentini inşa edebilmesi.
