# Contributing

Thanks for wanting to improve this repository! Here's how to get started.

## Ways to contribute

- Fix typos or clarify explanations in the docs
- Add runnable example code (Python or JavaScript)
- Share new free resources (books, papers, courses, tools)
- Suggest or write project ideas
- Improve the glossary

## How to submit

1. Fork this repository.
2. Create a new branch: `git checkout -b your-improvement`
3. Make your changes.
4. Commit with a clear message: `git commit -m "Add ...`
5. Push: `git push origin your-improvement`
6. Open a pull request describing what you changed and why.

## Guidelines

- Write in clear, simple English.
- Keep code examples minimal and runnable.
- All resources must be free / openly licensed.
- Be respectful and welcoming to learners of all levels.
